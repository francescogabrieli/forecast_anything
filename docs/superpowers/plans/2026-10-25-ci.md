# CI and Local Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Check formatting, lint, tests, and package builds on pull requests for Python 3.12 and 3.14.

**Architecture:** A GitHub Actions workflow uses uv's locked environment across a 3.12/3.14 matrix. Each job runs the same Ruff checks, tests, and wheel/sdist build; README records the equivalent local commands.

**Tech Stack:** GitHub Actions, uv, Ruff, pytest, hatchling.

**Spec:** [CI design](../specs/2026-10-25-ci-design.md).

## Global Constraints

- Preserve Python `requires-python = ">=3.12"`.
- Reproduce dependencies from `uv.lock`; CI must fail on a stale lock.
- Python formatting is checked with Ruff; no JavaScript/TypeScript or Prettier is introduced.
- Pull request workflows use least-privilege read-only repository permissions.
- GitHub Actions references are pinned to immutable commit SHAs.

## Review Focus

1. Python 3.12 and 3.14 each resolve and test using the checked-in lock.
2. CI and the documented local commands invoke identical checks.
3. Ruff's explicit rules and formatter produce a clean baseline without lint autofixes in CI.
4. Workflow syntax and all pinned action references are valid.
5. The build produces both wheel and source distribution in both matrix jobs.
