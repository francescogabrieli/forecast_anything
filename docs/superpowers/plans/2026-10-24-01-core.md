# Future Graph Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [x]) syntax for tracking.

**Stato:** C1–C6 implementati il 25 ottobre 2026; integrazione del branch da approvare. Estensioni delle interfacce e limiti sono registrati in [core.md](../../implementation/core.md).

**Goal:** produrre un nucleo utilizzabile da CLI, con dati point-in-time, grafo verificato ed emissioni immutabili.

**Architecture:** libreria Python indipendente dagli agenti. Il grafo produce piani ordinati; un runtime esegue provider e operatori registrati e pubblica risultati tramite un registro transazionale.

**Tech Stack:** Python 3.12, Pydantic 2, NumPy, SQLite, pytest, uv.

**Spec:** [specifica approvata](../specs/2026-10-24-forecast-anything-design.md); coordinamento nella [roadmap](../../roadmap.md).

## Global Constraints

- “Il prodotto principale è l’infrastruttura open source; Afterplot è una possibile applicazione.”
- “La visione resta generale: non viene definito un settore esclusivo.”
- “Un aggiornamento crea una nuova emissione, senza modificare quella precedente.”
- “Event time e momento di disponibilità del dato sono distinti.”
- “Gli agenti restano sostituibili.”
- Tutti i path di codice sotto indicati sono relativi alla root del repository.

## Review Focus

1. Timestamp senza fuso e cambio DST: rifiuto o normalizzazione esplicita — C1/C2.
2. Correzioni tardive o identità duplicate: selezione della revisione disponibile, mai informazione futura — C2.
3. Cicli, input mancanti e unità incompatibili: errore strutturato prima dell’inferenza — C3.
4. Crash tra risultato ed evento: entrambi persistono oppure nessuno — C4.
5. Retry e fallimento del provider: nessun duplicato, provenienza e stato coerenti — C5.

## Mappa dei file e convenzioni condivise

Creare .gitignore, pyproject.toml, uv.lock, src/forecast_anything/__init__.py, contracts.py, temporal.py, graph.py, store.py, runtime.py, cli.py, providers/base.py, providers/baseline.py, connectors/csv.py; tests/unit/, tests/integration/; examples/minimal/graph.json e observations.csv.

Il contratto JSON v1 usa ISO 8601 con fuso e valori finiti. I valori mancanti sono null, non NaN/Infinity nel wire format. I test possono usare NumPy internamente. I tipi condivisi di base sono definiti in contracts.py; i piani successivi aggiungono esplicitamente i propri tipi:

| Tipo | Campi obbligatori e significato |
| --- | --- |
| Observation | series_id, event_time, available_at, revision, value: float oppure None, unit |
| Snapshot | snapshot_id, as_of, observations: tuple[Observation, ...], assumptions: tuple[str, ...] |
| Node | node_id, kind: source/forecast/transform/event, inputs: tuple[str, ...], config: dict |
| GraphSpec | graph_id, version: int, nodes: tuple[Node, ...] |
| CompiledGraph | spec: GraphSpec, order: tuple[str, ...], dependencies: dict[str, tuple[str, ...]] |
| Capabilities | provider_id, provider_revision, representations: tuple[str, ...], supports_known_future: bool |
| OperatorContract | name, required_representation: str, units_rule: str |
| ForecastRequest | snapshot: Snapshot, horizon: int, frequency: str, known_future: Snapshot oppure None |
| ForecastResult | provider_id, provider_revision, series_ids, timestamps, units, point, quantiles, paths, sample_group_id, assumptions |
| RunRecord | run_id, graph_id, graph_version, as_of, snapshot_ids, requested_provider: dict[str, str], actual_provider: dict[str, str], state, results: dict[str, ForecastResult], evidence_ids, scenario_id: str oppure None, parent_run_id: str oppure None |
| EventRecord | cursor: int, event_id, kind, run_id, payload: dict |
| DomainError | code: str, details: dict; eccezione serializzabile |

NodeValue è l’unione Snapshot oppure ForecastResult. Operator è il protocollo definito nel task C5: contract() -> OperatorContract; apply(inputs: dict[str, NodeValue], config: dict) -> ForecastResult.

ForecastResult.point ha forma serie × orizzonte; quantiles è None oppure dict[livello come stringa, matrice serie × orizzonte]; paths è None oppure campioni × serie × orizzonte. I tre campi includono solo ciò che il provider supporta. sample_group_id è obbligatorio per paths e identifica traiettorie congiunte allineate; campioni di gruppi diversi non sono automaticamente combinabili. units è indicizzato per serie. I dizionari dei provider di RunRecord sono indicizzati per node_id, poiché un grafo può usare modelli diversi. Lo stato di RunRecord descrive l’esecuzione, non la qualità statistica. La prima implementazione del calendario numerico supporta frequenze intere orarie o giornaliere; altre frequenze richiedono una capacità esplicita.

def test_graph_revision_is_immutable(tmp_path):

def test_seasonal_repetition():
    t = datetime(2026, 10, 24, tzinfo=timezone.utc)
    observations = tuple(
        Observation(
            series_id="s",
            event_time=t - timedelta(hours=4 - i),
            available_at=t,
            revision="1",
            value=v,
            unit="count",
        )
        for i, v in enumerate((10, 20, 10, 20))
    )
    result = SeasonalNaiveProvider(period=2).forecast(
        ForecastRequest(
            snapshot=freeze(observations, t),
            horizon=3,
            frequency="1h",
            known_future=None,
        )
    )
    assert list(result.point[0]) == [10, 20, 10]
~~~
